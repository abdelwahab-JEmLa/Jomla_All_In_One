## Étape 3 — Contenu de `context_agy.md` généré

**Chemin** : `skill_agent/copy_context/copy_au_externale_chat_ai/historique_explication/08_26 07_05 ProductList_Sort_Fix/context_agy.md`

```markdown
fix todo avec la facon la plus rapide (ne pas ecrire "todo resolved" ou "TODO resolved" a la fin)

TODO dans `ProductListFilterLogic.kt` ligne 87 :

    // TODO: cc_ trier d''abord par catalogue.position, puis par catégorie.positionDouble
    //       ignorer le classement quand prioritize_cartons = false
    return products.sortedWith(
        compareBy { classement[it.keyID] }  // ← incorrect
    )

**Contexte architectural** :
- `groupAndSort()` est appelé depuis `b_List_LazyColumnList_App4.kt` (App4/VendeurHost) et `MainLazyList_App2.kt` (App2/PresenterScreen).
- Quand `prioritize_cartons = false` (PresenterScreen), le tri final doit être uniquement :
  catalogue.position → catégorie.positionDouble, sans tenir compte du `classement`.
- Le modèle `M3CouleurProduitInfos` contient les champs `cataloguePosition: Int` et `categorie.positionDouble: Double`.
```
