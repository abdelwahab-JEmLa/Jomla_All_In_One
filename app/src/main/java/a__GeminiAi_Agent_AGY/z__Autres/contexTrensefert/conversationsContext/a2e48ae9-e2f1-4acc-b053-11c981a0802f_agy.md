This file documents the exact codebase changes and file structure implemented to add Room, CSV, and Firebase synchronization operations for the models **M10OperationVentCouleur**, **M13TarificationInfos**, and **M14VentPeriode**, as well as the batch Multi-Operations panel.

## Codebase Context Summary

### 1. Database & CSV Helper Methods
Added to [Setter_LongDatas.kt](file:///C:/Users/Abou%20Mohamed/AndroidStudioProjects/Light_App_Controles/app/src/main/java/EntreApps/Shared/Modules/Base/Setter_LongDatas.kt):
- **M10OperationVentCouleur**:
  - `delete_All_M10()`: Clears local Room table.
  - `insertAll_M10(items)`: Batch upserts operations to Room database.
  - `get_Firebase_M10_Counts(ref)`: Fetches remote child counts.
  - `export_M10_Room_To_Csv(csv)`: Exports Room database entries to a CSV file.
  - `set_scv_M10_au_fireBase(csv, ref)`: Parses CSV rows and uploads to Firebase.
  - `import_M10_FireBase_To_Csv(ref, csv)`: Downloads Firebase snapshot to local CSV file.
  - `import_M10Csv_To_Room(csv)`: Imports CSV rows to local Room database.
  - `import_M10_FireBase_To_Room(ref)`: Downloads data directly from Firebase to Room.
- **M13TarificationInfos**:
  - `delete_All_M13()`, `insertAll_M13()`, `get_Firebase_M13_Counts()`, `export_M13_Room_To_Csv()`, `set_scv_M13_au_fireBase()`, `import_M13_FireBase_To_Csv()`, `import_M13Csv_To_Room()`, `import_M13_FireBase_To_Room()`.
- **M14VentPeriode**:
  - `delete_All_M14()`, `insertAll_M14()`, `get_Firebase_M14_Counts()`, `export_M14_Room_To_Csv()`, `set_scv_M14_au_fireBase()`, `import_M14_FireBase_To_Csv()`, `import_M14Csv_To_Room()`, `import_M14_FireBase_To_Room()`.
