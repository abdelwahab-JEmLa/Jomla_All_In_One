## Codebase Context Summary

### 1. Database & CSV Helper Methods
Added to [Setter_LongDatas.kt](file:///C:/Users/Abou%20Mohamed/AndroidStudioProjects/Light_App_Controles/app/src/main/java/EntreApps/Shared/Modules/Base/Setter_LongDatas.kt):

- `insertAll_M01Produit(items)`: Batch upserts products to Room database.
- `get_Firebase_M01Produit_Counts(ref)`: Fetches remote child counts.
- `export_M01Produit_Room_To_Csv(csv)`: Exports Room database entries to a CSV file.
- `set_scv_M01Produit_au_fireBase(csv, ref)`: Parses CSV rows to entities and uploads to Firebase.
- `import_M01Produit_FireBase_To_Csv(ref, csv)`: Downloads Firebase snapshot to local CSV file.
- `import_M01ProduitCsv_To_Room(csv)`: Imports CSV file rows to local Room database.
- `import_M01Produit_FireBase_To_Room(ref)`: Downloads data directly from Firebase to Room.
- `m01_from_Map(map)`: Reconstructs `M01Produit` from string key-value maps.
