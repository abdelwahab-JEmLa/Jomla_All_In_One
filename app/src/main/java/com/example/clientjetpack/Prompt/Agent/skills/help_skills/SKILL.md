## 📂 Gestion des Références de Projets (`ref_<nom>`)

Lorsque l’assistant rencontre un mot-clé ou déclencheur sous la forme `ref_<nom>` (par exemple `ref_DevApp`, `ref_agy_c`), il **doit** :
1. Lire le fichier de configuration [references.json](file:///C:/Users/Abou%20Mohamed/.gemini/antigravity-cli/references.json) à la racine de l’espace de travail.
2. Rechercher dans `projects` la clé dont la liste `noms` contient le nom demandé (par exemple `DevApp` ou `agy_c`), de manière insensible à la casse.
3. Extraire le chemin `path` spécifié pour ce projet.
4. Appliquer ce `path` comme répertoire racine cible pour toutes les lectures, écritures, recherches de fichiers ou exécutions de commandes liées à ce projet.
